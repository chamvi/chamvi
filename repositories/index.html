Stores and repositories ​

The engine receives an IStore object with one implementation per persistence capability. Each role has its own small interface and can be built and tested independently.

IStore has nine required fields: runs, steps, checkpoints, idempotency, locks, effects, state, artifacts and agentRevisions. Its optional conversations field implements IConversationRepository, its optional connections field IConnectionRepository (needed by createConnectionVault(), e.g. for the WhatsApp session store). Pass the aggregate as new Engine({ store, agents }); use store.runs.findOne(id) or store.state.findOne(agent, key) for direct access. IStore is a plain aggregate, not a facade with forwarding methods. Conversation storage alone does not enable memory: configure conversations: { authorize, limits? } on the engine and opt agents in.

Updating existing callers ​

This changes the storage API. IStore now aggregates individual repository interfaces rather than forwarding all operations through one facade. The MemoryStore and TypeormStore classes are removed; custom adapters assemble their capabilities into an IStore object.

Conversation memory is new in 0.4: its storage is store.conversations (both built-in stores carry it) and its policy is createApp({ conversations: { authorize } }) or EngineOptions.conversations. There is nothing to migrate from 0.3.

Keep passing the aggregate through new Engine({ store, agents }), storeModule({ store }) and AppToken.STORE. Factory option types are MemoryStoreOptions and DatabaseStoreOptions; createDatabaseStore() returns DatabaseStore.

The package is now @chamvi/store-db (previously @chamvi/store-typeorm). Replace package imports and dependencies; database tables and migration history keep their names. The class split itself changes no database schema; 0.4's conversation and taint migration does, and it needs downtime: follow Upgrading to 0.4. Existing TypeORM roles must keep sharing the same DataSource so their relationships remain valid.

Query methods ​

findOne(...) returns one record or undefined. find(...) returns the repository's existing collection shape: run queries return { data, total }, while steps, artifacts, state and agent revisions return arrays. Conversation item/note queries return { data, total } through findItems and findNotes.

The matching OrFail method returns the same result when it exists. findOneOrFail(...) throws for undefined; stored state values such as null, false, 0 and '' are valid results. findOrFail(...) throws when the selected array or page is empty, including a run query with limit: 0 or an offset beyond the last result even when total is nonzero. Query validation is unchanged: conversation queries require limit >= 1, so their limit: 0 is a validation error. Qualified queries follow the same rule: findDocumentsOrFail, findItemsOrFail, findNotesOrFail and findOneNoteOrFail.

A missing single run or artifact uses RunNotFoundError or ArtifactNotFoundError; other missing repository results use RepositoryNotFoundError. Backend failures and validation errors pass through unchanged. Leases and mutations retain their domain operations, such as claim, renewClaim and beginTurn.

ts
const run = await store.runs.findOneOrFail(runId);
const { data, total } = await store.runs.find({ agent: run.agent, limit: 20 });
const artifacts = await store.artifacts.find(runId);

Rules every repository keeps ​

  1. One expiry rule. A claim, key or lock created at time T with ttlMs is expired at exactly T + ttlMs and can be taken over at that instant.
  2. Time comes from the clock. Expiry decisions use an injected IClock, never the database's clock, so tests can drive time and replicas agree on one rule.
  3. No aliasing. Values are copied in and out. Mutating an object after passing it to the store, or one the store returned, never changes what the store holds.
  4. Atomic means atomic across callers. runs.insert, idempotency.claim, runs.claim, runs.renewClaim, locks.acquire, artifacts.insert and artifacts.save must hold under concurrency, also across processes.
  5. Ordering. runs.find orders by createdAt ascending, ties broken by id ascending, or both descending with order: 'desc' (newest first); total ignores limit and offset. artifacts.find orders the same way. agentRevisions.find orders by agent name in code-point order.
  6. Guards throw. runs.update throws InvalidRunStateError when expectStatus does not match, or when expectOwner is given and the claim is absent or held by another owner (expiry is not checked there: a lease is lost once taken over), or when expectWaitId is given and the run's wait id differs or it has no wait point. It throws RunNotFoundError for an unknown run.
  7. Checkpoints. checkpoints.save keeps the highest stepIndex; an equal index replaces.
  8. State filters. state.findDocuments where matches top-level fields by equality.
  9. Run references. steps.insert, checkpoints.save and conversations.beginTurn for a run the store does not hold throw RunNotFoundError and write nothing. createMemoryStore() checks its own run repository; the database store maps the foreign key violation.
  10. Artifacts. artifacts.insert resolves false and keeps the stored metadata and bytes when the id exists, or when key is given and the run already holds an artifact under that key. artifacts.save is an atomic upsert by (runId, key) and resolves the stored metadata: an absent key inserts the artifact as given, an existing one keeps its id, agent and createdAt and replaces mediaType, filename (a missing one removes it), size and the bytes. The key is private to the store: no read returns it, and findOneByKey(runId, key) is the only lookup by it. Bytes are copied in and out like every other value, and read returns a plain Uint8Array (no Buffer or other subclass). findOne and find return metadata only.

The interfaces ​

ts

import type { AgentRevision } from '../agent/types.ts';
import type { Artifact } from '../artifact/types.ts';
import type {
    Connection,
    ConnectionConfig,
    ConnectionConfigWrite,
    ConnectionEntryWrite,
    ConnectionFence,
} from '../connection/types.ts';
import type { IConversationRepository } from '../conversation/types.ts';
import type {
    Checkpoint,
    Run,
    RunStatusLiteral,
    Step,
    WaitPoint,
} from '../run/types.ts';

export type RunFindOptions = {
    agent?: string;
    /** Only the runs of these agents (an empty list matches none; an AND with `agent`). */
    agents?: readonly string[];
    status?: RunStatusLiteral[];
    concurrencyKey?: string;
    /** Only these run ids (an empty list matches none). */
    ids?: readonly string[];
    /** Only the runs dispatched by this run (`Run.parentRunId`). */
    parentRunId?: string;
    /** Only the runs dispatched by one of these runs (an empty list matches none). */
    parentRunIds?: readonly string[];
    /** Only the runs dispatched by some run (`true`, `Run.parentRunId` set) or by none (`false`). */
    hasParent?: boolean;
    /** Only the runs whose wait point (`Run.waiting`) is of this kind. */
    waitKind?: WaitPoint['kind'];
    limit?: number;
    offset?: number;
    order?: 'asc' | 'desc';
};

export type RunUpdateOptions = {
    expectStatus?: RunStatusLiteral[];
    expectOwner?: string;
    expectWaitId?: string;
    /** Keep the stored updatedAt when the patch sets none (default: stamped with now), for derived fields such as subtreeUsage. */
    keepUpdatedAt?: boolean;
};

export type StateFindOptions = { limit?: number; offset?: number };

export type StateDocumentFindOptions = { where?: Record<string, unknown>; limit?: number };

/**
 * Query contract: findOne returns undefined when absent; find returns an empty
 * result when nothing matches. Their OrFail counterparts throw on absence or an
 * empty selected page, even if records exist outside that page. Falsy values
 * (including null) count as present. They preserve each query's ordering and copies.
 *
 * Expiry rule shared by every TTL (run claims, idempotency keys, locks):
 * a lease/key created at time T with ttlMs expires AT T + ttlMs, i.e. at exactly
 * `expiresAt` it already counts as expired and can be taken over.
 *
 * Implementations must return copies: mutating a value passed in after the call,
 * or a value returned from a repository, must never change what it holds.
 */
export interface IRunRepository {
    /**
     * Atomic insert-if-absent: resolves false and keeps the stored run when a run
     * with that id exists (two dispatches may create the run an idempotency key names).
     * Sets `parentRunId` from `trigger.parent.runId` (a given `parentRunId` is
     * ignored); a parent run the store does not hold throws RunNotFoundError
     * and writes nothing.
     */
    insert(run: Run): Promise<boolean>;
    findOne(id: string): Promise<Run | undefined>;
    findOneOrFail(id: string): Promise<Run>;
    /**
     * Throws InvalidRunStateError when `expectStatus` does not match the current
     * status, or when `expectOwner` is given and the run's claim is absent or held
     * by another owner (expiry is not checked: a lease is lost once taken over),
     * or when `expectWaitId` is given and the run has no wait point or its wait
     * id (`id`, else `approvalId`) differs. A stored wait point without `id`
     * reads back with `id = approvalId`.
     */
    update(id: string, patch: Partial<Run>, opts?: RunUpdateOptions): Promise<Run>;
    /**
     * Ordered by createdAt, ties broken by id, both ascending (`order` `asc`,
     * the default) or both descending (`desc`). `total` ignores limit/offset.
     * Without `limit`, every matching run (from `offset`) is returned: there is
     * no default page size.
     */
    find(q: RunFindOptions): Promise<{ data: Run[]; total: number }>;
    findOrFail(q: RunFindOptions): Promise<{ data: Run[]; total: number }>;
    /** Atomic: only succeeds when unleased or the lease expired. */
    claim(id: string, owner: string, ttlMs: number): Promise<boolean>;
    /** Extends the lease; only succeeds for the current, unexpired owner. */
    renewClaim(id: string, owner: string, ttlMs: number): Promise<boolean>;
}

export interface IStepRepository {
    /** The parent run must already exist. */
    insert(step: Step): Promise<void>;
    find(runId: string): Promise<Step[]>;
    findOrFail(runId: string): Promise<Step[]>;
}

export interface ICheckpointRepository {
    /**
     * Keeps the highest stepIndex; an equal stepIndex replaces (approval responses are appended that way).
     * The parent run must already exist.
     */
    save(cp: Checkpoint): Promise<void>;
    findOne(runId: string): Promise<Checkpoint | undefined>;
    findOneOrFail(runId: string): Promise<Checkpoint>;
}

export interface IIdempotencyRepository {
    /** Atomic: the first caller per (scope, key) creates; others get the winner's runId. */
    claim(scope: string, key: string, runId: string, ttlMs: number): Promise<{ created: boolean; runId: string }>;
}

export interface ILockRepository {
    /** Atomic: only succeeds when the key is unleased or its lease expired. */
    acquire(key: string, owner: string, ttlMs: number): Promise<boolean>;
    /**
     * Atomic: extends the lease to `now + ttlMs` and resolves true only while
     * `owner` holds it unexpired; false when absent, expired, released or held
     * by another owner (the lease is never re-created).
     */
    renew(key: string, owner: string, ttlMs: number): Promise<boolean>;
    /** Releasing a lease held by another owner (or none) is a no-op. */
    release(key: string, owner: string): Promise<void>;
}

export interface IEffectRepository {
    findOne(key: string): Promise<{ result: unknown } | undefined>;
    findOneOrFail(key: string): Promise<{ result: unknown }>;
    save(key: string, result: unknown): Promise<void>;
}

export interface IStateRepository {
    findOne(agent: string, key: string): Promise<unknown>;
    findOneOrFail(agent: string, key: string): Promise<unknown>;
    /** `undefined` removes the key. */
    set(agent: string, key: string, value: unknown): Promise<void>;
    /**
     * One agent's entries ordered by key in code-point order (`COLLATE "C"`),
     * values copied out; every entry (from `offset`) without `limit`.
     */
    find(agent: string, q?: StateFindOptions): Promise<Array<{ key: string; value: unknown }>>;
    findOrFail(agent: string, q?: StateFindOptions): Promise<Array<{ key: string; value: unknown }>>;
    /** `where` matches by top-level equality. */
    findDocuments(
        agent: string,
        coll: string,
        q?: StateDocumentFindOptions,
    ): Promise<Array<{ id: string; doc: unknown }>>;
    findDocumentsOrFail(
        agent: string,
        coll: string,
        q?: StateDocumentFindOptions,
    ): Promise<Array<{ id: string; doc: unknown }>>;
    upsertDocument(agent: string, coll: string, id: string, doc: unknown): Promise<void>;
    deleteDocument(agent: string, coll: string, id: string): Promise<void>;
}

/** Files of runs (attachments and tool outputs): metadata and bytes, both copied in and out. */
export interface IArtifactRepository {
    /**
     * Atomic insert-if-absent: resolves false and keeps the stored artifact
     * (metadata and bytes) when an artifact with that id, or with `key` in
     * that run, exists. The key is private to the store: no read returns it.
     */
    insert(artifact: Artifact, data: Uint8Array, key?: string): Promise<boolean>;
    /**
     * Atomic upsert by `(runId, key)`. An absent key inserts the artifact as given;
     * an existing one keeps its `id`, `agent` and `createdAt`, replaces `mediaType`,
     * `filename` (removed when absent), `size` and the bytes, and resolves the stored
     * metadata.
     */
    save(artifact: Artifact, data: Uint8Array, key: string): Promise<Artifact>;
    /** Metadata only. */
    findOne(id: string): Promise<Artifact | undefined>;
    findOneOrFail(id: string): Promise<Artifact>;
    /** Metadata of the run's artifact stored under `key`. */
    findOneByKey(runId: string, key: string): Promise<Artifact | undefined>;
    /** The bytes, as a plain Uint8Array (no Buffer or other subclass). */
    read(id: string): Promise<Uint8Array | undefined>;
    /** Metadata of a run's artifacts, ordered by createdAt ascending, ties broken by id ascending. */
    find(runId: string): Promise<Artifact[]>;
    findOrFail(runId: string): Promise<Artifact[]>;
}

/** One revision marker per folder agent, keyed by agent name, copied in and out. */
export interface IAgentRevisionRepository {
    findOne(agent: string): Promise<AgentRevision | undefined>;
    findOneOrFail(agent: string): Promise<AgentRevision>;
    /** Upsert: replaces the hash and `changedAt` of an existing marker. */
    save(revision: AgentRevision): Promise<void>;
    /** Deleting a missing marker is a no-op. */
    delete(agent: string): Promise<void>;
    /** Every marker, ordered by agent in code-point order (`COLLATE "C"`). */
    find(): Promise<AgentRevision[]>;
    findOrFail(): Promise<AgentRevision[]>;
}

/**
 * Connections, their runtime-state entries (opaque sealed bytes: the
 * repository never sees plaintext) and their config (plain settings and sealed
 * secrets, kept apart from the entries). Values are copied in and out as plain
 * Uint8Arrays. A name breaking the agent-name rule, an entry key outside 1 to
 * 255 characters or with NUL, a secret field outside 1 to 64 characters or
 * with NUL, or a malformed batch throws ValidationError before anything is
 * written; entry calls on an unknown connection throw RepositoryNotFoundError.
 */
export interface IConnectionRepository {
    /** Atomic insert-if-absent: resolves false and keeps the stored connection when the name is taken. */
    insert(connection: Connection): Promise<boolean>;
    findOne(name: string): Promise<Connection | undefined>;
    findOneOrFail(name: string): Promise<Connection>;
    /** Every connection, ordered by name in code-point order (`COLLATE "C"`). */
    find(): Promise<Connection[]>;
    /**
     * Removes the connection with its entries and config; a missing name is a
     * no-op. With `fence`, it must name the lease `connection:<name>` its owner
     * holds unexpired at write time, checked atomically with the delete;
     * otherwise LeaseLostError and nothing is deleted.
     */
    delete(name: string, fence?: ConnectionFence): Promise<void>;
    /**
     * Atomic, all or nothing: swaps the connection of `connection.name` for
     * `connection` (inserts it if absent), dropping its entries and secrets
     * (they are sealed under the replaced data key) and keeping its settings
     * and config revision. The replacement is
     * validated as by `insert` (ValidationError) before anything else; `fence`
     * must name the lease `connection:<name>` its owner holds unexpired at
     * write time, checked atomically with the write; otherwise LeaseLostError
     * and nothing changes.
     */
    replace(connection: Connection, fence: ConnectionFence): Promise<void>;
    findEntry(name: string, key: string): Promise<Uint8Array | undefined>;
    /** The stored ones of `keys`; missing keys are absent from the map. */
    findEntries(name: string, keys: readonly string[]): Promise<Map<string, Uint8Array>>;
    /**
     * Atomic, all or nothing: `clear`, then `set`, then `delete`, and
     * `updatedAt` set to now. `fence` must name the lease `connection:<name>` its owner holds
     * unexpired at write time, checked atomically with the write; otherwise
     * LeaseLostError and nothing is written.
     */
    writeEntries(name: string, write: ConnectionEntryWrite, fence: ConnectionFence): Promise<void>;
    /**
     * A consistent read of the data key (`keyId`, `wrappedKey`), settings,
     * sealed secrets and revision; undefined when the connection is absent.
     */
    findConfig(name: string): Promise<ConnectionConfig | undefined>;
    /**
     * Atomic; bumps `revision` and `updatedAt` and returns the new revision.
     * RepositoryNotFoundError when absent; ConnectionChangedError when the
     * stored wrappedKey differs from `expectedWrappedKey` (nothing is
     * written). Takes no fence: any replica may write while a session holds
     * the lease, and entries and the data key stay untouched.
     */
    writeConfig(name: string, write: ConnectionConfigWrite, expectedWrappedKey: Uint8Array): Promise<number>;
}

/** A store of repositories that may use independent storage implementations. */
export interface IStore {
    runs: IRunRepository;
    steps: IStepRepository;
    checkpoints: ICheckpointRepository;
    idempotency: IIdempotencyRepository;
    locks: ILockRepository;
    effects: IEffectRepository;
    state: IStateRepository;
    artifacts: IArtifactRepository;
    agentRevisions: IAgentRevisionRepository;
    conversations?: IConversationRepository;
    connections?: IConnectionRepository;
}
