On this page

@chamvi/core ​

The public API of @chamvi/core, taken from packages/core/src/index.ts. Contract interfaces carry an I prefix (IRunRepository, IClock, IChannel, IAgentState); data shapes are unprefixed types.

ts
import { Engine, defineModelAgent } from '@chamvi/core';

Test helpers live in @chamvi/test-kit.

Agents ​

ts
function defineModelAgent<S extends StateSchema = StateSchema>(def: ModelAgentDefinition<S>): ModelAgent<S>;
function defineSimpleAgent<S extends StateSchema = StateSchema>(def: SimpleAgentDefinition<S>): SimpleAgent<S>;

const DEFAULT_MAX_STEPS: 20;
const DEFAULT_TIMEOUT_MS: 900_000; // 15 minutes

Throws InvalidAgentDefinitionError for an invalid name, instruction outer shape or role, duplicate subscription ids, a tool with needsApproval or a toolsContext entry naming a chamvi tool or no tool of a plain tool set (both in a plain tool set; a tools factory fails the run instead), defineModelAgent() also for run. Agent is ModelAgent | SimpleAgent, told apart (and narrowed, the definition too) by kind ('model' or 'simple'); AgentDefinition is ModelAgentDefinition | SimpleAgentDefinition. The engine refuses an agent whose kind is neither or disagrees with its definition (a simple agent needs a function run, a model agent has none). defineSimpleAgent() also throws for a non-function run, a tools factory or any of model, instructions, skills, output, conversation, toolsContext; its run(payload, ctx: SimpleRunContext) gets the tool context plus ctx.tools. See Agents.

A folder agent's agent.ts default-exports defineModelAgent()'s or defineSimpleAgent()'s result, named like its folder (rebuilt through the factory of its kind; one without kind, from an older core, as a model agent unless it has run); AgentRevision is the store's revision marker of a folder agent (see Agent Folders):

ts
/*

 * Author Peter Placzek (tada5hi)
 * For the full copyright and license information,
 * view the LICENSE file that was distributed with this source code.
 */

import type {
    AssistantModelMessage,
    OutputInterface,
    SystemModelMessage,
    ToolSet,
    UserModelMessage,
} from 'ai';
import type { ChannelSubscription } from '../channel/types.ts';
import type { ModelRef } from '../model/types.ts';
import type { Budget, RunContext } from '../run/types.ts';
import type { StateSchema } from '../state/types.ts';
import type { SkillInput } from '../skill/types.ts';
import type { AgentTrust, ToolContext } from '../tool/types.ts';

/** The factory's argument: the same ToolContext the run's chamvi tools get. */
export type ToolFactoryContext<S extends StateSchema = StateSchema> = ToolContext<S>;

/**
 * Decides per tool name whether a run may use a tool. A refused tool is not
 * offered to the model (it is left out of `activeTools`). A call to it that
 * still arrives is a tool error, never a run failure, and its tool step
 * records `tool_not_allowed` (ToolNotAllowedError) on both paths:
 * - the model calls it anyway: the AI SDK answers the model with its
 *   unavailable-tool error (NoSuchToolError), the engine records the step
 *   as ToolNotAllowedError;
 * - a call pending on an approval (the policy changed before the resume)
 *   reaches the engine's per-call re-check, which answers the model with
 *   ToolNotAllowedError.
 * Should depend only on the run snapshot (e.g. `run.trigger.invoker`), so
 * the tool set is stable across executions.
 */
export type ToolPolicy = (toolName: string, ctx: { run: RunContext }) => boolean;

/** A tool call as the agent hooks see it. */
export type ToolCallInfo = {
    toolName: string;
    toolCallId: string;
    input: unknown;
};

/**
 * Gates and rewrites for every tool call of the agent's merged set (user,
 * chamvi, state and third-party tools alike), run inside the tool-call frame
 * with the execution's ToolContext (`inject` works there).
 */
export type AgentHooks = {
    /**
     * Runs before the effect lookup and returns the input to execute with
     * (`undefined` keeps it). A changed input is re-validated against the
     * tool's input schema (a failure is a ValidationError tool error) and is
     * what the effect key is computed from. A throw is a tool error
     * (ToolDeniedError for a refusal); a FatalToolError fails the run.
     */
    beforeToolExecution?(call: ToolCallInfo, ctx: ToolContext): unknown | Promise<unknown>;
    /**
     * Runs on a fresh result and on a recorded effect result alike and returns
     * the output the model sees (`undefined` keeps it). A streaming tool's
     * hook gets its final value. Not called for a tool error.
     */
    afterToolExecution?(call: ToolCallInfo & { output: unknown }, ctx: ToolContext): unknown | Promise<unknown>;
};

/** Trusted configured messages; tool-role messages are never instruction inputs. */
export type AgentInstruction = SystemModelMessage | UserModelMessage | AssistantModelMessage;

/** A string is shorthand for one system message. Arrays retain their authored order. */
export type AgentInstructions = string | readonly AgentInstruction[];

/** An agent whose runs call a language model: defineModelAgent()'s input. */
export type ModelAgentDefinition<S extends StateSchema = StateSchema> = {
    name: string;

    /** The text of the agent's MCP run tool; default: its leading system instruction. */
    description?: string;

    /** Only a simple agent has it (defineSimpleAgent()). */
    run?: never;

    /**
     * `'<provider>/<model id>'` (resolved through EngineOptions.models) or a
     * LanguageModel object; without it the agent uses EngineOptions.model.
     */
    model?: ModelRef,

    instructions: AgentInstructions,

    readonly skills?: readonly SkillInput[],

    /**
     * The channels that start the agent's runs (e.g. `cron.on('0 8 * * 1-5')`);
     * every subscription names a channel registered on the engine, ids are
     * unique per agent.
     */
    channels?: ChannelSubscription[];

    /** Shared-store execution cap across all channels; omitted or false adds no cap. */
    concurrencyMaxRuns?: number | false;

    /** Only principals granted `agent:<name>:read` read the agent's runs (and state). */
    private?: boolean;

    /**
     * The agent's tools: a plain `ToolSet` (the default), or a factory for
     * dynamic sets, called once per execution with the same ToolContext the
     * tools get. Tools built with `defineTool`/`defineEffectTool` receive that
     * context as `context` in `execute`.
     */
    tools?: ToolSet | ((ctx: ToolContext<S>) => ToolSet);

    trust?: AgentTrust;

    /**
     * Per tool name, the context of a tool that is not chamvi's (e.g. a
     * third-party tool with its own `contextSchema`), passed through unchanged
     * by reference to every call of every run: treat it as immutable. An entry
     * naming a chamvi tool or no tool is an InvalidAgentDefinitionError (at
     * defineModelAgent for a plain set, a failed run for a factory).
     */
    toolsContext?: Record<string, unknown>;

    /**
     * Tool hooks (see AgentHooks). AI SDK tools declaring their own
     * `needsApproval` are refused (nothing answers that request).
     */
    hooks?: AgentHooks;

    /** Filters the merged tool set (state tools included) per run, e.g. requireToolPermission(). */
    toolPolicy?: ToolPolicy;

    /** Record<collection, StandardSchemaV1>. */
    state?: S;

    budget?: Partial<Budget>;

    /**
     * Structured output (AI SDK `Output`, e.g. `Output.object({ schema })`):
     * a completed run's `output` is the parsed value instead of the text; a
     * final answer that does not parse fails the run with a ValidationError.
     */
    output?: OutputInterface;

    /**
     * Opts the agent into conversation memory (needs
     * EngineOptions.conversations); runs that come with no conversation still
     * execute as before. Omitted or false: no conversation behaviour.
     */
    conversation?: boolean | {
        /** Stable memory identity across agent renames; default is the agent name. */
        key: string;
    };
};

/**
 * What a simple agent's `run()` gets: the ToolContext its tools would get, plus
 * its own tools (wrapped like a model's calls: effect-recorded,
 * trust-classified, gated) as plain functions by name.
 */
export type SimpleRunContext<S extends StateSchema = StateSchema> = ToolContext<S> & {
    tools: Record<string, (input: unknown) => Promise<unknown>>;
};

/**
 * A model-free agent, defineSimpleAgent()'s input: the engine runs `run(payload, ctx)` as a durable run
 * inside one tool-call frame, so dispatch(), waitForDispatch(), approve(),
 * ctx.channels and the agent's tools work as inside a tool call. A suspended
 * run re-runs `run()` from the start on resume (the replay rule).
 */
export type SimpleAgentDefinition<S extends StateSchema = StateSchema> = {
    name: string;

    /** The run's body; its JSON-serialisable return value is the run's `output`. */
    run(payload: unknown, ctx: SimpleRunContext<S>): unknown | Promise<unknown>;

    /** The text of the agent's MCP run tool. */
    description?: string;

    channels?: ChannelSubscription[];

    concurrencyMaxRuns?: number | false;

    /** Only principals granted `agent:<name>:read` read the agent's runs (and state). */
    private?: boolean;

    /** A plain set only: a factory is refused. */
    tools?: ToolSet;

    trust?: AgentTrust;

    hooks?: AgentHooks;

    toolPolicy?: ToolPolicy;

    state?: S;

    /** `timeoutMs` and the subtree budget apply; `maxSteps` and `maxTokens` do not. */
    budget?: Partial<Budget>;

    model?: never;
    instructions?: never;
    readonly skills?: never;
    output?: never;
    conversation?: never;
    toolsContext?: never;
};

export type AgentDefinition<S extends StateSchema = StateSchema> = ModelAgentDefinition<S> | SimpleAgentDefinition<S>;

/** defineModelAgent()'s result: its definition with the budget defaults applied. */
export type ModelAgent<S extends StateSchema = StateSchema> = {
    readonly kind: 'model';
    readonly name: string;
    readonly definition: Required<Pick<ModelAgentDefinition<S>, 'budget'>> & ModelAgentDefinition<S>;
};

/** defineSimpleAgent()'s result: its definition with the budget defaults applied. */
export type SimpleAgent<S extends StateSchema = StateSchema> = {
    readonly kind: 'simple';
    readonly name: string;
    readonly definition: Required<Pick<SimpleAgentDefinition<S>, 'budget'>> & SimpleAgentDefinition<S>;
};

/** A registrable agent; `kind` tells the two apart and narrows the definition. */
export type Agent<S extends StateSchema = StateSchema> = ModelAgent<S> | SimpleAgent<S>;

/**
 * The revision marker of a folder agent: the content hash of its folder
 * (never its code) and when that hash was recorded.
 */
export type AgentRevision = {
    agent: string;
    hash: string;
    changedAt: Date;
};

Native messages and instructions ​

Core exports the unchanged native SDK types SystemModelMessage, UserModelMessage, AssistantModelMessage, ModelMessage, UserContent, AssistantContent, TextPart, ImagePart and FilePart. App re-exports these through its normal core barrel. System content is a string; user/assistant multipart content and provider options retain their native SDK types.

AgentInstruction is the union of native system/user/assistant messages; AgentInstructions accepts a string or readonly array of that union. Tool roles and a single-object shorthand are refused. Leading system blocks use SDK instructions; all remaining configured messages stay ordered in a transient prefix. Skills runtime metadata adds a separate system block, while manual catalog metadata stays a string. Prefixes hydrate files without entering checkpoints or pending-tool replay; restored transcript system roles are rejected. See the typed instructions example.

import type { ApprovalDecision, ApprovalOption, ApprovalRequestInput } from '../approval/types.ts';
import type { ConversationTarget } from '../conversation/types.ts';
import type { DispatchEnvelope, IEngine } from '../engine/types.ts';
import type { TriggerEnvelope } from '../trigger/types.ts';

/** The HTTP input of a channel: the raw web request (body unread) and the raw subpath after `/channels/<name>`. */
export type ChannelRequest = {
    request: Request;
    subpath: string;
};

/** What a channel may dispatch: the engine sets `channel` to the channel's own name. */
export type ChannelDispatchEnvelope = Omit<DispatchEnvelope, 'channel'>;

/** What `engine.dispatch()` resolves. */
export type DispatchResult = {
    runId: string;
    deduplicated: boolean;
};

export type ChannelContext = {
    engine: IEngine;
    /** engine.dispatch with `channel` set to this channel's name (a channel cannot dispatch as another). */
    dispatch(envelope: ChannelDispatchEnvelope): Promise<DispatchResult>;
    /** Trusted, registered-channel intake; the channel supplies canonical identity and accepted text. */
    dispatchConversation(envelope: ChannelDispatchEnvelope, target: ConversationTarget): Promise<DispatchResult>;
};

/** One outbound message; `key` is stable per logical message and the transport's dedupe key. */
export type ChannelMessage = {
    kind: 'message' | 'approval';
    key: string;
    runId: string;
    agent: string;
    title?: string;
    body: string;
    /** Named persistent message where supported (GitHub); omitted messages append. */
    slot?: string;
    /** Set for kind `approval`. */
    approvalId?: string;
    /** Set for kind `approval`. */
    expiresAt?: Date;
    /** Set for kind `approval` with options (without their artifacts, which stay in the inbox and API). */
    options?: Omit<ApprovalOption, 'artifacts'>[];
    /** Set (true) for kind `approval` with options of which several may be selected. */
    multiple?: boolean;
};

export type ChannelSendOptions = {
    signal: AbortSignal;
    /** The run's stored envelope: a transport may read the source payload, never write it. */
    trigger: TriggerEnvelope;
};

/**
 * Anything a run can come from or talk to. The presence of `start`, `in`
 * and `out` is the only capability; `name` follows the agent-name rules
 * and is unique per engine.
 */
export interface IChannel<TInput = ChannelRequest, TOutput = Response> {
    readonly name: string;
    /** Intake authored by external parties taints every triggered run. */
    readonly untrusted?: boolean;
    /**
     * Where `emit()` and `approve()` send when the tool names no address and
     * the run did not come from this channel (e.g. OpenClaw's `deliver.to`);
     * a non-empty string. Without it such a call needs an address.
     */
    readonly defaultAddress?: string;
    /** Background inbound (cron ticks, sockets, polling); called by engine.start() after the first recover. */
    start?(ctx: ChannelContext): Promise<void>;
    /** Called first by engine.drain() and engine.stop(): no new inbound. */
    stop?(): Promise<void>;
    /** The channel's single inbound entry; transports feed it (the http route, a socket loop, tests). */
    in?(input: TInput, ctx: ChannelContext): Promise<TOutput>;
    /** Sends a message to an address the channel defines; idempotent on `message.key`. */
    out?(message: ChannelMessage, address: string, opts: ChannelSendOptions): Promise<void>;
}

/**
 * An agent's subscription to a channel (replaces the trigger definition):
 * `channel` names a channel registered on the engine, `id` is unique
 * within the agent, `options` belong to the channel.
 */
export type ChannelSubscription<P = unknown> = {
    channel: string;
    id: string;
    /** Shared-store execution cap within this agent; omitted or false adds no cap. */
    concurrencyMaxRuns?: number | false;
    options: Record<string, unknown>;
    // method signatures (bivariant): a ChannelSubscription<P> fits AgentDefinition.channels
    concurrencyKey?(payload: P): string | undefined;
    idempotencyKey?(payload: P): string | undefined;
    /** The run's address from its payload; read by the agent channel only (`agent.on()`). */
    address?(payload: P): string | undefined;
};

/** A message a tool emits; `key` overrides the content-addressed dedupe key. */
export type EmitMessage = {
    title?: string;
    body: string;
    key?: string;
    /** Named persistent message where supported (GitHub); omitted messages append. */
    slot?: string;
};

/**
 * A channel bound to the run (`ToolContext.channels`). `address` is
 * the run's source address when this is the run's source channel, else the
 * channel's `defaultAddress`.
 */
export type ChannelHandle = {
    readonly name: string;
    readonly address?: string;
    /**
     * Sends `message` through the channel's `out` to `address` (default: the
     * bound address), at most once per key; only inside a tool call.
     */
    emit(message: EmitMessage, address?: string): Promise<void>;
    /** Asks the owner to approve, durably (suspends the tool call until answered). */
    approve(request: ApprovalRequestInput & { address?: string; slot?: string }): Promise<ApprovalDecision>;
};

/**
 * `ToolContext.channels`: run-bound handles on the engine's channels with
 * `out`. On the run's source channel a handle defaults to the source address.
 */
export type ToolChannels = {
    /**
     * The channel `name` (default: the run's source channel); undefined when
     * the engine has no such channel or it has no `out`.
     */
    findOne(name?: string): ChannelHandle | undefined;
    /** As findOne(), but ChannelNotFoundError instead of undefined. */
    findOneOrFail(name?: string): ChannelHandle;
    /** Every engine channel with `out`, in registration order. */
    find(): ChannelHandle[];
};

export type ConsoleChannelOptions = {
    /** Default `'console'`. */
    name?: string;
    /** Receives each line; default `console.log`. */
    write?: (line: string) => void;
};

consoleChannel() writes [chamvi] <kind>: <title or the body's first line> (agent <agent>, run <runId>, key <key>), then the body lines and, for an approval, with options select one: (or select one or more:) and one option <id>: <label> line per option, then approval <approvalId> waits until <ISO>, one write call per line. It never throws; an invalid name throws InvalidAgentDefinitionError.

The envelope (TriggerEnvelope, Invoker):

ts
/*
 * Copyright (c) 2026.
 * Author Peter Placzek (tada5hi)
 * For the full copyright and license information,
 * view the LICENSE file that was distributed with this source code.
 */

import type { Artifact } from '../artifact/types.ts';

/**
 * Who started a run (or answered an approval), as an authenticator resolved
 * it: a snapshot of identity and grants taken at dispatch, never a token.
 * Revoking a grant later does not reach a run that already holds it.
 */
export type Invoker = {
    id: string;
    /**
     * The authenticator's label: `@chamvi/http`'s staticTokens() sets
     * 'token' and authup() sets 'authup'; oidc() keeps the kind its
     * `principal` mapper returns (the docs use 'oidc'); a custom authenticator
     * or a direct dispatch may use its own (e.g. 'user').
     */
    kind: string;
    name?: string;
    permissions: readonly string[];
};

/**
 * The run that dispatched this one. Only the engine-internal host sets it;
 * a dispatch() envelope never carries one, so no caller forges lineage.
 */
export type TriggerParent = {
    kind: 'dispatch';
    runId: string;
    /** The parent run's agent. */
    agent: string;
    /** The dispatch role of the child agent this run was started through. */
    role: string;
    depth: number;
    /**
     * The one channel and address the dispatching code named for this run
     * (`dispatch(ctx, { source })`): its outbound gate exempts that
     * destination like a run's own source. Never from a generated dispatch tool.
     */
    source?: TriggerSource;
};

/** A channel and an address on it, as `dispatch()`'s `source` names it. */
export type TriggerSource = {
    channel: string;
    address: string;
};

export type TriggerEnvelope<P = unknown> = {
    id: string;
    agent: string;
    /** The id of the agent's subscription that started the run. */
    trigger: string;
    /** The name of the channel the run came from. */
    channel: string;
    payload: P;
    idempotencyKey?: string;
    concurrencyKey?: string;
    /** Where the run came from on that channel (an issue, a thread, a caller); the channel defines it. */
    address?: string;
    /** Files the run was started with, stored as artifacts of the run; the model gets them as file parts. */
    attachments?: Artifact[];
    /**
     * Who started the run; only ever set from an authenticator (never from a
     * payload). Absent for runs a channel started without one (cron, webhooks). With an invoker the
     * idempotency key is scoped to it, so only the same invoker's dispatch
     * is deduplicated (and gets its own first run).
     */
    invoker?: Invoker;
    /** The run that dispatched this one; set only by dispatch(), never from engine.dispatch(). */
    parent?: TriggerParent;
    receivedAt: Date;
};

agent.on() (dispatch roles) is in core, see Dispatch. The other subscription builders live in the channel packages: http.on() and webhook.on() in @chamvi/http, cron.on() in @chamvi/channel-cron, github.on() in @chamvi/github. See Channels & the Envelope.

Engine ​

Use IEngine for engine type annotations and Engine for construction or extension. IEngine describes every public engine member and extends IContextProvider; it is also re-exported by @chamvi/app.

getChannel, listChannelsOne registered channel by name; all of them in registration orderChannels
putAgentRegisters an agent or replaces the one of the same name in place (a new one goes last); refuses a subscription to an unknown channel like the constructor. Replacing cancels the agent's unsettled runs created before now. With a revision (a folder's content hash) the store's marker is brought to it under the lock agents:<name> instead, cancelling once across replicas and only when a marker existed (swept before and again after the marker write; no run of the agent starts on this engine meanwhile). Each cancelled run stores agent_replaced as its error (Errors), and the sweep emits agents.cancelled. With reload: false (a process that never reloads, a job) nothing is cancelled: a missing marker is written, a different one moved only while the agent has no unsettled run, else InvalidRunStateError and the agent stays unregistered. A marker at formerRevision (the same content hashed by an earlier algorithm) counts as equal and is moved to revision without a cancel. Optional signal cancels preparation and rejects with its reason before registry mutation, retaining the previous agent, marker and runs. ts
function resolveModel<S extends StateSchema = StateSchema>(ctx: ToolContext<S>, ref?: ModelRef): LanguageModel;

A ModelRef is a '<provider>/<model id>' string or an AI SDK LanguageModel object (used as is). An agent's model falls back to EngineOptions.model; the engine refuses an agent with neither, a ref of another shape, a string without EngineOptions.models (IModelResolver; pass a LanguageModel object then) and a string the resolver refuses, at construction and in putAgent (checkAgentModel is that check; a string default without a resolver is refused at construction too). Strings resolve through models.resolve() when an execution starts; the engine never hands the AI SDK a string. @chamvi/app passes both from its model settings (CHAMVI_MODEL, chamvi.json, createApp({ model, providers })).

resolveModel(ctx, ref?) gives tool code (execute, the tools factory, the effect hooks) a model: ref, else the run's agent model from the live registry, else the default. An object is returned as is; a string needs models (resolveModel(): the model string "<ref>" needs a model resolver (EngineOptions.models).) and a ref it cannot resolve is an InvalidAgentDefinitionError too, a tool error in execute. It reads the engine's models through the context mechanism, so ToolContext keeps its shape and a hand-built context throws ContextNotProvidedError.

/*

import type { StandardSchemaV1 } from '@standard-schema/spec';
import type { FlexibleSchema } from 'ai';
import type { Agent } from '../agent/types.ts';
import type { ChannelSubscription, DispatchResult } from '../channel/types.ts';
import type { DispatchEnvelope } from '../engine/types.ts';
import type { IEffectRepository, IRunRepository } from '../repository/types.ts';
import type { Invoker, TriggerParent, TriggerSource } from '../trigger/types.ts';

export type AgentSubscriptionOptions<P = unknown> = {
    /** The role (the subscription id), following the channel-name rule; default `default`. */
    role?: string;
    /** Parses the payload a tool dispatches; the parsed value is the child's payload. */
    schema?: StandardSchemaV1<unknown, P>;
    /** How many dispatches of this role one run may start (all executions together), default 100. */
    maxPerRun?: number;
    /** The other agents whose runs may dispatch to this role (agent names); the own agent always may. */
    from?: string[];
    /** The deepest a run of this role may sit in a dispatch tree (a root run has depth 0), 1 to 8, default 1. */
    maxDepth?: number;
    /** Shared-store execution cap within the agent; omitted or false adds no cap. */
    concurrencyMaxRuns?: number | false;
    /** The child's concurrency key when the call gives none. */
    concurrencyKey?(payload: P): string | undefined;
    /** The child's idempotency key when the call gives none. */
    idempotencyKey?(payload: P): string | undefined;
    /** The child's address when the call gives none; deterministic (it feeds the dispatch's dedupe key). */
    address?(payload: P): string | undefined;
    /** What the role does, for a generated dispatch tool's description. */
    description?: string;
};

/** Makes a role of the `agent` channel (subscription id = role): the opt-in for dispatch(). */
export type AgentSubscriber = {
    on<P = unknown>(options?: AgentSubscriptionOptions<P>): ChannelSubscription<P>;
};

export type DispatchInput = {
    /** The receiving `agent.on()` role; default `default`. */
    role?: string;
    /** The child run's payload (required), parsed by the role's schema. */
    payload: unknown;
    /** Dedupes across runs: a second dispatch under the same key gets the first child. */
    idempotencyKey?: string;
    concurrencyKey?: string;
    /** The child's `trigger.address` (and `Run.address`). */
    address?: string;
    /**
     * A channel and address the child may `emit()` and `approve()` to
     * without the outbound gate, as if it were the child's own source
     * (stored as `trigger.parent.source`). The exemption is only as safe as
     * the code choosing it: take the address from trusted data (an API
     * response read in code), never from model input. Generated dispatch
     * tools never set it.
     */
    source?: TriggerSource;
};

/** dispatchTo()'s input: a dispatch to the `agent.on()` role of `agent`. */
export type DispatchToInput = DispatchInput & {
    /** The receiving agent (the calling run's own agent behaves as dispatch()). */
    agent: string;
};

/** How a dispatched run ended, as waitForDispatch() reports it. */
export type DispatchOutcome = {
    runId: string;
    agent: string;
    role: string;
    /** `timeout`: the wait expired on a run another run dispatched (it keeps running), or on one whose cancel did not land within one claim TTL. */
    status: 'completed' | 'failed' | 'cancelled' | 'timeout';
    /** A completed run's output. */
    output?: unknown;
    /** A failed or cancelled run's error (a wait that expired: code `Timeout`). */
    error?: { code: string; message: string };
};

export type DispatchWaitOptions = {
    /** How long the run waits before the wait expires; 1 to APPROVAL_TIMEOUT_MAX_MS, default 24 h. */
    timeoutMs?: number;
};

/** What `dispatch-wait:<runId>:<waitId>` records (internal): the outcomes in `runIds` order, the tainted run ids. */
export type DispatchWaitRecord = {
    outcomes: DispatchOutcome[];
    tainted: string[];
};

/** The engine's copy of a run dispatch() reads (internal). */
export type DispatchRunSnapshot = {
    readonly runId: string;
    readonly agent: string;
    readonly invoker?: Invoker;
    readonly parent?: TriggerParent;
};

/** The engine side of dispatch() (internal, provided under DISPATCH_CONTEXT). */
export type DispatchHost = {
    getAgent(name: string): Agent | undefined;
    /** True for a channel registered on the engine. */
    hasChannel(name: string): boolean;
    effects: IEffectRepository;
    runs: Pick<IRunRepository, 'findOne' | 'find'>;
    /** Creates the run with `parent` as its lineage (engine.dispatch() never sets one). */
    createRun(envelope: DispatchEnvelope, parent: TriggerParent): Promise<DispatchResult>;
    /** Runs `fn` after every earlier call of the same run settled (the count and children read-check-write). */
    serial<T>(runId: string, fn: () => Promise<T>): Promise<T>;
    /** Dispatches in flight by effect key, so identical parallel calls share one. */
    inflight: Map<string, Promise<DispatchResult>>;
};

/**
 * A role schema as a generated tool's input: the AI SDK schema the model
 * sees and validates against, and how a validated input becomes the payload.
 */
export type RoleToolInput = {
    inputSchema: FlexibleSchema<unknown>;
    toPayload(input: unknown): unknown;
};

export type DispatchToolsOptions = {
    /** Roles of the calling agent: one `dispatch_<role>` tool each, calling dispatch(). */
    roles?: string[];
    /** Roles of other agents: one `dispatch_<agent>_<role>` tool each, calling dispatchTo(). */
    agents?: { agent: string; roles: string[] }[];
    /** Every generated tool waits for its child (waitForDispatch()) and returns the DispatchOutcome. */
    wait?: boolean | DispatchWaitOptions;
};

/** What a dispatchTools() placeholder stands for (internal): `agent` unset for the calling agent. */
export type DispatchToolTarget = {
    agent?: string;
    role: string;
    wait: false | DispatchWaitOptions;
};

dispatch(), dispatchTo() and waitForDispatch() run inside a tool call (or a simple agent's run()) only (InvalidRunStateError elsewhere; waitForDispatch() also in a streaming tool's body). A missing role, a caller not in from, a too deep child, the per-run limit, an invoker without agent:<target>:run, a held concurrency key and a run this run did not dispatch are ValidationError tool errors (a simple agent's run fails instead); a reached budget.maxSubtreeTokens is a BudgetExceededError tool error. dispatchTools() throws InvalidAgentDefinitionError for no role, a bad name, a name over 64 characters, a role listed twice or a bad wait. See Dispatch and Generated dispatch tools.
