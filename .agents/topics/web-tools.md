# Web Tools

Read before changing `@chamvi/tool-web`.

`@chamvi/tool-web` holds `webTools({ client?, lookup?, allowUrl?, maxBytes?, timeoutMs?, clock? })`, one plain `defineTool()` tool, `web_fetch`, that runs in the chamvi process; it peers on core and `ai` and depends on `hapic` (requests and proxy), `mdream` (HTML to markdown or text, a Rust core with prebuilt binaries per platform and a WASM fallback) and `smob`. Options are checked when called (`InvalidAgentDefinitionError`).

- **Request** (`getPage()`, `request/module.ts`; the URL check in `url/`, the options in `options/`): a GET through the hapic client (default `createClient()`, whose `FetchTransport` takes the proxy from `HTTP_PROXY`/`HTTPS_PROXY`/`NO_PROXY`) with `redirect: 'manual'` and `responseType: 'stream'`; redirects followed by hand (at most `WEB_MAX_REDIRECTS` 5); before every hop `parseWebUrl` (http(s) only, no credentials, `ValidationError`) and `checkUrl` (`allowUrl(url)`: `true` allows, `false` refuses, `undefined` resolves the host through `lookup` (default `dns.lookup`, every address) and refuses a host with any address `isBlockedAddress()` holds, `ValidationError`); the body read up to `maxBytes` (default `WEB_FETCH_MAX_BYTES` 5 MiB, the rest cancelled, `truncated`); `timeoutMs` (default `WEB_TIMEOUT_MS` 30 s) on the `IClock` over the whole fetch; a 4xx/5xx status, a network failure and the timeout are `ChamviError`s with code `web_request` (`WEB_REQUEST_ERROR_CODE`), tool errors. The request resolves the name again, so DNS rebinding and a proxy's own connect are not covered (documented; an egress policy is the operator's tool).
- **Address check** (`address/`): `parseAddress()` (IPv4/IPv6 to bytes, brackets and a trailing dotted quad allowed), `isBlockedAddress()` over `BLOCKED_IPV4`/`BLOCKED_IPV6` (this network, RFC 1918, CGNAT, loopback, link-local and metadata, multicast, reserved, documentation, benchmarking; IPv4-mapped, NAT64 and 6to4 judged by the IPv4 inside; anything that is no IP address is blocked).
- **`web_fetch({ url, format?, offset? })`** (`tools/fetch.ts`): a type that is no text (`isText`: `text/*`, JSON, XML, scripts, `+json`/`+xml`, none) is a `web_request` error; the body decoded by its charset (or `<meta charset>`, else UTF-8); an HTML page converted inline by mdream to markdown (`htmlToMarkdown`) or text (`htmlToText`): links and images absolute against the page URL, `javascript:` and `data:` links turned into their text (`clean.emptyLinks`), the main content isolated (`minimal`), and for a page without main or article (or a fragment, which isolates to nothing) the whole body without `PAGE_CHROME_ELEMENTS`; the title read through mdream's frontmatter callback, the frontmatter stripped; `raw` returns the body; at most `WEB_FETCH_MAX_CHARS` 65 536 characters from `offset` (never inside a surrogate pair, an offset past the end a `ValidationError`), `nextOffset` while more follows. Package registries are plain JSON URLs the description names (`https://registry.npmjs.org/<name>`, `https://pypi.org/pypi/<name>/json`); there is no registry or search tool.

## Module map

| Path | Purpose |
|------|---------|
| `address/` | No barrel: `parseAddress()`, `isBlockedAddress()` (`module.ts`), `BLOCKED_IPV4`, `BLOCKED_IPV6` (`constants.ts`) |
| `url/` | `parseWebUrl()`, `checkUrl()` (`module.ts`: `allowUrl`, then the address check over `lookup`), `systemLookup` (`lookup.ts`, `dns.lookup` with every address), `WebAddress`, `WebLookup`, `WebUrlPolicy` (`types.ts`, the only export) |
| `request/` | `getPage()` (`module.ts`: the hapic GET, manual redirects each through `checkUrl`, the timeout on the `IClock`), `requestError()`, `messageOf()`, `readCapped()` (`asserts.ts`), `WEB_FETCH_MAX_BYTES`, `WEB_TIMEOUT_MS`, `WEB_MAX_REDIRECTS`, `WEB_REQUEST_ERROR_CODE` (`constants.ts`, exported), `WebResponse` (`types.ts`, internal) |
| `options/` | `normalizeOptions()` (`module.ts`, `InvalidAgentDefinitionError` for bad options), `TIMER_MAX_MS` (`constants.ts`), `WebToolsOptions` (exported) and `WebToolsOptionsNormalized` (`types.ts`) |
| `html/` | No barrel: `mediaTypeOf()`, `isHtml()`, `isText()`, `decodeBody()`, `htmlToMarkdown()`, `htmlToText()` (`module.ts`, both through mdream), `TEXT_MEDIA_TYPES`, `PAGE_CHROME_ELEMENTS`, `FRONTMATTER` (`constants.ts`), `ConvertedPage` (`types.ts`) |
| `tools/` | `webTools()` (`module.ts`), `webFetchTool()` (`fetch.ts`), the tool input helpers `inputObject()`, `requireString()`, `optionalInteger()`, `optionalOneOf()`, `signalOf()`, `cutText()`, `objectSchema()` (`asserts.ts`), `WEB_FETCH_MAX_CHARS` (exported), `WEB_FETCH_FORMATS`, `UNTRUSTED_NOTE` (`constants.ts`), `WebFetchFormat`, `WebFetchResult` (`types.ts`) |

## Testing

- `@chamvi/tool-web` tests never reach the network: `createFakeWeb()` (`test/utils/web.ts`) is a hapic client over an in-memory `fetch` (`routes` per URL, `calls`), a fake `lookup` (`dns` per host, a public address by default, `lookups`) and route helpers (`html`, `text`, `json`, `redirect`, `hang`); the timeout test arms `hang`, waits for the call, then advances the `ControllableClock`.
