# Core Module Map

Read before adding or moving a file in `@chamvi/core` or `@chamvi/test-kit`.

## Module map (`packages/core/src`)

Every module is a folder with `module.ts`, `types.ts`, `asserts.ts`, `constants.ts` and an `index.ts` barrel as needed (see [conventions](../conventions.md#file-organization)).

| Path | Purpose |
|------|---------|
| `errors/` | `ChamviError` (`base.ts`), one file per subclass, `ErrorCode` (`constants.ts`) |
| `context/` | `defineContextKey()`, `inject()`, `tryInject()` (`module.ts`), `ContextKey`, `IContextProvider` (`types.ts`), the key `WeakSet` and the ToolContext `WeakMap`: `registerContextKey()`, `isContextKey()`, `bindProvided()`, `providedOf()`, `contextKeyName()` (`asserts.ts`, internal); `ContextNotProvidedError` lives in `errors/context-not-provided.ts` |
| `agent/` | `defineModelAgent()`, `AgentDefinition`, `AgentHooks`, `ToolCallInfo`, `AgentRevision` (`types.ts`), name rules and budget defaults (`constants.ts`), `assertToolsContext()`, `assertNoNeedsApproval()` (`asserts.ts`, internal) |
| `trigger/` | `TriggerEnvelope` (`channel`, `address`, `parent`), `TriggerParent`, `Invoker` (`types.ts`), `assertTriggerKey()` (`key.ts`), `TRIGGER_KEY_MAX_LENGTH` (`constants.ts`), `normalizeEnvelope()` (public: the legacy `source`/`thread` read-back for repositories), `toInvoker()`, `idempotencyScope()` (`asserts.ts`, internal) |
| `channel/` | `IChannel`, `ChannelRequest`, `ChannelContext`, `ChannelDispatchEnvelope`, `DispatchResult`, `ChannelMessage`, `ChannelSendOptions`, `ChannelSubscription`, `EmitMessage`, `ChannelHandle`, `ToolChannels`, `ConsoleChannelOptions` (`types.ts`); `consoleChannel()` (`console.ts`); `agentChannel()` (`agent.ts`); `AGENT_CHANNEL_NAME` (`constants.ts`); `assertChannelName()`, `createToolChannels()` (`ToolContext.channels`), `createChannelHandle()` (the emit effect and `approve()` with a channel) (`asserts.ts`, internal); `ChannelNotFoundError` lives in `errors/channel-not-found.ts` |
| `artifact/` | `Artifact`, `ArtifactInput`, `ArtifactFilePart`, `IRunArtifacts` (`types.ts`); `ARTIFACT_URI_PREFIX` (`constants.ts`, internal); `artifactFilePart()` (public), `createRunArtifacts()`, `storeArtifact()`, `attachmentIds()` (`module.ts`, the last three internal); `isArtifactMediaType()` (`media-type.ts`, public); `assertArtifactInput()`, `toFilePart()`, `hydrateMessages()` (`asserts.ts`) |
| `run/` | `RunStatus` enum (`constants.ts`); `Run` (optional durable `taint`, `parentRunId`, `subtreeUsage`), `RunTaint`, `RunStatusLiteral`, `Step`, `Checkpoint`, `WaitPoint` (`ApprovalWaitPoint | DispatchWaitPoint`), `Budget` (`maxSubtreeTokens`), `Usage`; `normalizeWaitPoint()`, `waitIdOf()` (`helpers.ts`, public: the legacy approval `id` read-back for repositories) |
| `repository/types.ts` | `IStore` aggregate and its capability interfaces (see architecture) |
| `repository/memory/` | `createMemoryStore()` and separate `Memory*Repository` capability classes; steps, checkpoints and conversations take `MemoryRunReferenceOptions.hasRun` (wired to the store's `MemoryRunRepository.has()`) |
| `run/helpers.ts` | Also the internal shared abort-aware wait (`untilAborted()`) used by execution and memory-bound channel sends, not a public export. |
| `conversation/` | Optional conversation contract/types and limits, engine-local helpers, canonical store policy (`persistence/`, exposed only as `@chamvi/core/conversation/persistence`), `MemoryConversationRepository`, execution bindings (`context.ts`) and capability (`module.ts`); trusted intake is bound by `Engine.channelContext()`, explicit `memoryTools()` and `hasConversation()` (`tools.ts`). `IStore.conversations` carries the optional storage capability. |
| `engine/` | `Engine` (`module.ts`: channel start/stop and trusted intake, `pause()`, `resume()`, `answer()`, `deliverApproval()`), `IEngine` (`types.ts`), `skills/` (internal `EngineSkills` implementing `IEngineSkills`: input capture, runtime validation, preparation and contribution lookup; no lifecycle coordination), `RunEvent`, `RunDelta`, `DispatchEnvelope`, `ApprovalAnswer`, `EngineStartOptions` (`types.ts`), `budget.ts` (stop conditions), `queue/` (scheduler, the `prepareStart` guard), `execute/` (one streamed execution; `SuspendRequest` = `ApprovalRequest | DispatchWaitRequest` in `types.ts`; `pendingToolCalls()`, `withoutResults()`, `withToolResults()`, `executePendingCall()` in `asserts.ts` run the calls an approval suspended), `dispatch/` (`settledOutcomes()`, `answerDispatchWait()`, `expireDispatchWait()`, `healDispatchWaits()`, `cancelChildren()`, `recomputeSubtreeUsage()`, `onRunSettled()` in `module.ts`; `DispatchEngineContext`, `ResumeRecord`, `ResumeStep` in `types.ts`, built by the protected `dispatchContext()`; all internal), `registry/` (`withAgentLock()`, `agentCancelReason()`, `formatRevision()` (public) in `helpers.ts`; `cancelAgentRuns()`, `syncRevision()`, `claimRevision()`, `dropRevision()` in `module.ts`; `RegistryContext`, `CancelReason`; all internal), `AGENT_LOCK_TTL_MS`, `REVISION_PREFIX_LENGTH` (`constants.ts`, internal), `AgentChange`, `AgentRunsCancelled`, `EngineEvent` (`types.ts`) |
| `effect/` | `defineEffectTool()`, `effectMarker()` (`define.ts`), `wrapToolsForRun(tools, ctx, store, { allow?, hooks?, trust? })` (`wrap.ts`: the tool-call frame, hooks, trust gate/result taint, effect lookup, `SuspendSignal` catch), `EFFECT`, `WrapToolsOptions`; `runToolCall()`, `currentToolCall()` (`frame.ts`, internal: the `AsyncLocalStorage` tool-call frame), `ToolCallFrame` (`types.ts`, internal) |
| `tool/` | `ToolContext`, `ToolTrust` (boolean or async predicates, plus the `approvalDetail` hook of the outbound gate's private body), `AgentTrust` (approve/deny policy and boolean tool-name overrides) (`types.ts`), `toolContextSchema` (`constants.ts`), `defineTool()` (`define.ts`), `hasToolContext()` (`asserts.ts`, internal) |
| `trust/` | Internal execution-bound first-taint persistence and final-input outbound approval/deny gate (`module.ts`), plus the public `runSource(ctx)` (`module.ts`: the source channel and address bound at execution start, `RunSource` in `types.ts`, the only exports of `index.ts`); agent policy/name validation and tool-level `assertToolTrust()` (`asserts.ts`). Shared by tool wrappers, resolved channel sends and approvals, and extraction. |
| `extract/` | `extract(ctx, { schema, content, instructions?, model? })`, `ExtractOptions`, tool-less structured output memoized in effects; conservative schema allowlist (`schema.ts`, internal: anchored patterns, property, free-text and output caps in `constants.ts`) taints results outside the allowlist; independent output check (`output.ts`) and raw-JSON cache validation on replay. |
| `dispatch/` | `dispatch()`, `dispatchTo()` (`start.ts`), `waitForDispatch()` (`wait.ts`), `agent` (`agent.on()`, `subscription.ts`), `AgentSubscriptionOptions`, `AgentSubscriber`, `DispatchInput`, `DispatchToInput`, `DispatchOutcome`, `DispatchWaitOptions` (public) and the internal `DispatchHost`, `DispatchRunSnapshot`, `DispatchWaitRecord` (`types.ts`), `DEFAULT_DISPATCH_ROLE`, `DEFAULT_DISPATCH_MAX_DEPTH`, `DISPATCH_DEPTH_MAX`, `DEFAULT_MAX_DISPATCHES_PER_RUN`, `DEFAULT_DISPATCH_WAIT_TIMEOUT_MS` (public) and `DISPATCH_CONTEXT` (internal, key `dispatch`) (`constants.ts`), `findDispatchRole()`, `assertDispatchRoles()`, `ancestorsOf()`, `bindRunSnapshot()`/`runSnapshotOf()`, `readCount()`, `readChildren()`, `toWaitRecord()`, `claimKey()` (`helpers.ts`, internal), `findApprovalWaitBelow()` (`descendants.ts`, public: the batched approval walk http and cron share) |
| `approval/` | `approve()`, `outboundApproved()` (public: the outbound gate approved the current call) and the internal `requestApproval()`, `reserveApproval()`, `SuspendSignal` (`request.ts`), `ApprovalRequestInput`, `ApprovalDecision`, `ApprovalOption` (`types.ts`), `DEFAULT_APPROVAL_TIMEOUT_MS`, `APPROVAL_TIMEOUT_MAX_MS`, `APPROVAL_OPTIONS_MAX`, `APPROVAL_OPTION_ID_PATTERN`, `APPROVAL_OPTION_LABEL_MAX_LENGTH`, `APPROVAL_OPTION_DETAIL_MAX_LENGTH`, `APPROVAL_OPTIONS_DETAIL_MAX_LENGTH` (public), `SUSPENDED_RESULT` (internal) (`constants.ts`), `approvalDecisionKey()`, `toApprovalDecision()`, `toApprovalOptions()`, `assertSelectionShape()`, `toSelection()` (`helpers.ts`, internal) |
| `permission/` | `matchesPermission()`, `hasPermission()`, `toolPermission()` (`match.ts`), `requireToolPermission()` (`policy.ts`), `RequireToolPermissionOptions` (`types.ts`), `PERMISSION_ALL` (`constants.ts`, internal) |
| `message/` | Native SDK message/content aliases (`types.ts`), exported through the core barrel; internal instruction validation, normalization, leading-system split and transcript trust guards (`helpers.ts`). |
| `skill/` | Generic `SkillInput`, `ISkillRuntimeProvider`, `ISkillRuntime`, `ISkillPreparation`, `PreparedAgentSkills` and `SkillContribution` (`types.ts`); protocol compatibility and opaque input snapshots (`helpers.ts`). Engine coordinates preparation, cancellation, readiness and ordinary contributed tools. No skill domain types, catalogs, hashes, content, source caches, filesystem or SDK dependencies. |
| `state/` | `createAgentState()` (`module.ts`, validation via `@validup/standard-schema`), generated tools (`tools.ts`) |
| `model/` | `ModelRef`, `IModelResolver`, `ModelCheckOptions` (`types.ts`, public region) and the internal `ModelContext`; `checkAgentModel()`, `resolveModel()` (public) and `checkDefaultModel()` (`module.ts`); `toLanguageModel()` (`asserts.ts`, internal: the one resolution path of the engine and `resolveModel`); `MODEL_CONTEXT` (`constants.ts`, internal, key `model`) |
| `clock/` | `IClock`, `systemClock` |
| `keyring/`, `connection/` | Keyring and sealing, the connection vault, validation and handle types; see [connections.md](connections.md) |

`src/index.ts` re-exports each folder's `index.ts`. `@chamvi/test-kit` (`packages/test-kit/src`) holds `model/` (`mockModel`, `textModel`, `approvalModel`, `failingModel`, `MockPart`, `MockResponse`), `model/embedding.ts` (`mockEmbeddingModel`, `MockEmbeddingModel`), `skill-runtime/` (`fakeSkillRuntime`), `clock/` (`ControllableClock`), `conversation-contract/` (`describeConversationRepositoryContract`), `knowledge-contract/` (`describeKnowledgeRepositoryContract`, structural `Contract*` types, `KnowledgeRepositoryContractFactory`), `repository-contract/` (`describeRepositoryContract`), `workspace-contract/` (`describeWorkspaceContract`, `WorkspaceContractFactory`), `git-fixture/` (`createGitFixture`, `GitFixture`) and `github-fake/` (`createFakeGithub` in `module.ts`, `FakeGithub`, `FakeGithubOptions`, `FakeRequest`, `FakeRoute*`, `JwtClaims` in `types.ts`, the repository routes and `abortable()` in `asserts.ts`).
